Progressive Web App

Native Android WebAPK Minting

The application is configured as a standalone Progressive Web App compliant with Google Play's WebAPK minting service. When installed on Android devices running Chrome or Chromium browsers, the system automatically wraps the PWA into a native Android APK with:

  • ✓ Hardware-Accelerated Audio: Direct low-latency Web Audio API access for hydrophone telemetry without browser chrome.
  • ✓ Offline Hydrophone Cache: Service worker caching keeps bioacoustic dictionaries and offline annotation queues available in remote sandbars.
  • ✓ Native Android App Launcher: App appears in the Android application tray with adaptive maskable icon geometry.
Open in Chrome to Install View manifest.json

On Chrome for Android, tap the three dots in the upper right, then choose "Install app" to automatically mint and install the WebAPK on your device.

Containerized Edge Deployment

Docker & Docker Compose

Run the full-stack Gharial ISPA telemetry workbench anywhere with a single command — whether on field station Intel NUCs, Raspberry Pi edge devices, or cloud servers.

Docker Run (One-liner)

Standalone
docker build -t gharial-ispa:latest .

docker run -d \
  -p 3000:3000 \
  --name gharial-sparrow \
  -e GEMINI_API_KEY="your-gemini-key" \
  gharial-ispa:latest

Container binds to port 3000 and executes health checks against /api/health automatically.

Docker Compose

Multi-stage
# Clone and start with docker compose
git clone https://github.com/bheemaiah/gharial-ispa-sparrow-rlhf.git
cd gharial-ispa-sparrow-rlhf

docker compose up -d --build

Pre-configured with Alpine Node 22 runtime, production asset minification, and automatic container restart policies.

Field Research Foundation

Madras Crocodile Bank Trust (MCBT)

Founded in 1976 by Romulus Whitaker and Zai Whitaker, the Madras Crocodile Bank Trust and Centre for Herpetology (MCBT) in Mahabalipuram, Tamil Nadu is one of the premier crocodilian conservation and captive breeding institutions in the world.

Under the bioacoustic research initiative proposed by Dr. Bheemaiah Anil Kumar, multi-channel hydrophone arrays situated across MCBT's deep lagoons monitor the reproductive choruses and infrasonic communication of captive gharials to aid riverine reintroduction and wild population monitoring.
